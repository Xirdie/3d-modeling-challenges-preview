Rounded cube, holding edges

Beginner OBJ required Modeling

Done? Check your file The check is free; the full review is $9.

The brief

Model a cube about 8 cm on each side that stays a cube when subdivided: every edge rounds by the same small radius, the faces stay flat and the corners stay tidy.

Hold the edges with support loops (edge loops placed close to each edge), not with creases or bevel weights, so the shape lives in the topology itself. Export the cage (Subdivision modifier off), all quads.

Keep it under 600 faces, with no n-gons and no triangles. Each corner meets in a clean three-edge pole.

Spec

  • Size: 7.5-8.5 cm on each side
  • Faces: 600 or fewer (the cage, Subdivision off)
  • All quads: 0 n-gons, 0 triangles
  • Poles with 5 or more edges: 0
  • Closed mesh: 0 open edges, 0 non-manifold edges
  • Export: OBJ, Triangulate Faces off

How to export

Blender

  1. Select the cube in Object Mode.
  2. File > Export > Wavefront (.obj).
  3. Turn on Selection Only (Limit to: Selected Only in Blender 4), leave Triangulate Faces off (Triangulated Mesh) and keep Apply Modifiers on.
  4. Keep Scale at 1.00 and the default axes (Y up).

Then drop the file below.

Maya

  1. Windows > Settings/Preferences > Plug-in Manager: tick Loaded for objExport.mll.
  2. Select the cube.
  3. File > Export Selection, Files of type: OBJexport.
  4. Leave Materials off; your scene units (cm) are kept.

Then drop the file below.

3ds Max

  1. Select the cube.
  2. File > Export > Export Selected, Save as type: gw::OBJ-Exporter (*.OBJ).
  3. In the exporter: Faces: Polygons (not Triangles) and Flip YZ-axis on.
  4. Check that Scale matches your scene units.

Then drop the file below.

ZBrush

  1. Go to your lowest subdivision level (Geometry > SDiv 1).
  2. Tool > Export and save as .obj.

Then drop the file below.

Other

  1. Export Wavefront OBJ with triangulation off, so quads stay quads.
  2. Export one mesh at real-world scale.

Then drop the file below.
