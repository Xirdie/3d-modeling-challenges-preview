Heavy vs light ball

Beginner MP4 / PNG sequence Animation

Done? Check your file The check is free; the full review is $9.

The brief

Animate two balls of the same size dropped from the same height, side by side: a heavy bowling ball and a light beach ball.

Tell the weight with timing and spacing alone. The bowling ball falls fast, hits hard and barely bounces; the beach ball floats, bounces several times and drifts before it settles.

Still side-on camera, both balls fully in frame, 72 to 120 frames at 24 fps.

Spec

  • Length: 72-120 frames at 24 fps (3-5 s)
  • Two balls, same size, same drop height
  • Heavy ball: fast fall, tiny bounce
  • Light ball: slow fall, several floaty bounces
  • Still, side-on camera; both balls in frame
  • Export: H.264 MP4 or a PNG sequence

How to export

Blender

  1. Output Properties: Frame Rate 24 fps, Frame Start and End set to your shot.
  2. Output: File Format FFmpeg Video, Container MPEG-4, Video Codec H.264. Or File Format PNG for a frame sequence.
  3. Look through your side camera, then View > Viewport Render Animation.

Then drop the file below.

Maya

  1. Set the scene to 24 fps (Preferences > Settings > Working Units > Time) and the Time Slider to your shot.
  2. Windows > Playblast options: Format image, Encoding png. QuickTime and AVI playblasts don't open in browsers.
  3. Playblast from your side camera, then drop all the PNG frames together.

Then drop the file below.

3ds Max

  1. Set Time Configuration to 24 fps and the range to your shot.
  2. Tools > Preview - Grab Viewport > Create Preview Animation, or Render Setup > Common: Range, Render Output saved as PNG.
  3. Drop the PNG sequence (all frames at once).

Then drop the file below.

Other

  1. Any tool: export an H.264 MP4 or a numbered PNG sequence (shot_0001.png, shot_0002.png ...).
  2. 24 fps, a still camera, both balls fully in frame.

Then drop the file below.
