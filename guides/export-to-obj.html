Export Blender, Maya or 3ds Max to OBJ (keep your quads)

Blender: File > Export > Wavefront (.obj), Selection Only on, Triangulate Faces off, Apply Modifiers on. Maya: File > Export Selection > OBJexport (enable objExport.mll in the Plug-in Manager first). 3ds Max: File > Export > OBJ, Faces: Polygons. Leaving triangulation off keeps quads, which is what a topology check needs; glTF and FBX often arrive triangulated. .blend and .ma files can't open in a browser.

Blender

  1. Select the mesh in Object Mode.
  2. File > Export > Wavefront (.obj).
  3. Turn on Selection Only (Limit to: Selected Only in Blender 4) and Apply Modifiers; leave Triangulate Faces (Triangulated Mesh) off.
  4. Keep Scale at 1.00 and the default axes (Y up). Blender works in metres: a 10 cm mug exports as 0.1 units tall, and the units picker reads it as metres.

Maya

  1. Windows > Settings/Preferences > Plug-in Manager: tick Loaded (and Auto load) for objExport.mll.
  2. Select the mesh, then File > Export Selection, Files of type: OBJexport.
  3. Leave Materials off. Maya works in centimetres, which the units picker reads as centimetres.

3ds Max

  1. Select the object, then File > Export > Export Selected and choose gw::OBJ-Exporter (*.OBJ).
  2. In the exporter set Faces: Polygons (not Triangles) and Flip YZ-axis on, so the model stands Y up.
  3. Check that the scale matches your scene units.

ZBrush

  1. Go to your lowest subdivision level (Geometry > SDiv 1), so the export is the base mesh, not millions of faces.
  2. Tool > Export and save as .obj.

Why OBJ, and why triangulation off

An OBJ file lists every face with its corners, so a face with four corners stays a quad. Exporters that triangulate split each quad into two triangles, and glTF stores triangles only, so a topology check sees 0 quads. That is why CritPass's modeling challenges ask for OBJ: it can count your quads, n-gons and poles exactly. A GLB or FBX still gets the silhouette, proportion and brief grade, marked "topology not measured".

Scene files (.blend, .ma, .mb, .max, .ztl) are program formats that no browser can read: always export.

Animation challenges take a playblast instead: an H.264 MP4 or a numbered PNG sequence. Each animation exercise lists the playblast steps per program.
